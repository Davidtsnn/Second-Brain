# Festival Akquise

Proaktive Outreach an Festivals → Jannes als Foto/Video für Event-Coverage anbieten. Kein reaktives Warten auf Anfragen, sondern eigene Pipeline aufbauen.

## Ziel

- Festivals identifizieren, gezielt anschreiben und Jannes als Foto/Video Crew positionieren
- Wiederkehrende Festival-Jobs aufbauen statt Einzelaufträge

## Offen — Konzept-Skizze

- [ ] Welche Festivals? (Region, Genre, Größe definieren)
- [ ] Zielgruppe im Festival-Team: Marketing-Lead, Booking, Festival-Manager
- [ ] Unser Angebot konkret: Aftermovie, Social Cuts, Live-Foto-Dump für Story, On-Site Editing?
- [ ] Referenz-Reel zusammenstellen (was haben wir an Festival/Event/Nightlife Material?)
- [ ] Outreach-Template (Mail / DM)
- [ ] Preisrahmen festlegen
- [ ] Tracking-Liste angeschriebene Festivals (Status: angeschrieben / Gespräch / zu / abgesagt)
