# Social Media Konzept

## Was ist dieser Bereich

Social-Media-Konzepte für Personal Brands entwickeln und umsetzen. Das ist kein klassisches Freelancing, sondern ein eigenes Konzept-Framework: ein System das funktioniert, unabhängig vom Kunden.

Linix ist der erste Case auf dem das Konzept entwickelt und erprobt wird.

## Vision

Ein bewährtes, skalierbares Framework für Personal Brand Aufbau auf Social Media. Erst Linix als Case, dann weitere Kunden oder eigenes Produkt daraus bauen.
