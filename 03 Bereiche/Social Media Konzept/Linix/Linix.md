## Konzept-Empfehlung: "Cinematic Character" (Hybrid B+A)

Multicam-Cinematic-Look als visuelle Wiedererkennung + Persönlichkeit/Charakter als emotionaler Anker. Music Curation als Add-on wenn Linix Lust hat zu sprechen.

→ Macht ihn cinematic (USP gegen Standard-DJ-Content) UND menschlich (USP gegen anonyme Cinematic-Accounts). Beides zusammen ist die Lücke.

## Content-Säulen

| Säule | Anteil | Format |
|---|---|---|
| Performance | 40% | Multicam Live-Sets, Drops, Crowd Reactions — IG Reels + YouTube |

## Benchmark: Lucas Kleinecke

Lucas Kleinecke ist **nicht** als DJ-Vorbild relevant, sondern als Methoden-Vorbild. Er ist Personal Branding Stratege für Coaches/Unternehmer. Seine Methode auf einen DJ übertragen ist der Hebel.

**Kernprinzipien übertragen:**

| Lucas (Coach/Agency) | Linix (DJ) |
|---|---|
| Lead-Generierung über Brand | Bookings + Fan-Base über Brand |
| Authority-Content (Wissen teilen) | Performance + Curation Content |
| Talking-Head Reels | Multicam Performance Reels |
| Hook = Bold Claim / Pain Point | Hook = Drop / Crowd Moment / Visual |
| Trust durch Insights | Trust durch wiederkehrende Vibes |

## Mechaniken

- **Trial-Reel-Methode:** Eine Performance → 3 Edits mit unterschiedlichen Hooks → posten → Daten auswerten
- **Content Batching:** Ein Dreh = 4–6 Wochen Content einkalkulieren
- **Hook-Library:** 10–20 Varianten testen (Drop-First, Crowd-First, Face-First etc.)
- **Posting-Frequenz:** 4–7× pro Woche IG Reels, 1–2× YouTube pro Monat
- **Wiedererkennungs-Elemente:** Min. 1 wiederkehrendes Element pro Reel
