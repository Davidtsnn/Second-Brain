## Die Kernstrategie — Text-Overlay-Testing als Primärmechanismus

### Das Grundprinzip (Research-validiert)

```
Guter Clip + Guter Song
        ↓
3–5 Text-Overlays entwickeln (verschiedene Framings)
        ↓
Auf TikTok testen (1 Clip = 3–5 Varianten über mehrere Tage)
        ↓
Watch Completion + Share Rate bestimmt den Gewinner
        ↓
Gewinner-Variante auf Instagram deployen
```

Warum das der richtige Weg ist:

TikTok bestraft kleine Accounts nicht. Ein Account mit 0 Followern kann
mit dem richtigen Clip auf 500K Views kommen wenn der Algorithmus ihn pusht.
Die Variable die über algorithmischen Push entscheidet ist Watch Completion.
Der primäre Hebel für Watch Completion bei DJ-Content ist der Text-Overlay.

Research-Grundlage:
- Text-Overlays erhöhen Completion Rate um +32% (2025-Daten)
- Trending Audio boosted Reach um +48% und Engagement um +66%
- Videos unter 40% Completion werden algorithmisch supprimiert
- Threshold 2025: ~70% Completion = Expansion-Signal (verschärft von ~50% in 2024)

---

### Das Text-Overlay-System — 5 Framings pro Clip

Jeder starke Clip wird mit 5 verschiedenen Overlay-Typen getestet:

| Overlay-Typ | Beispiel | Mechanik | Primär-Metrik |
|---|---|---|---|
| Kein Text | — | Musik + Visual alleine | Share Rate (intrinsisch) |
| Location + Zeit | "Stuttgart, 2 Uhr morgens." | Atmosphäre, DACH-Identität | Watch Completion |
| Skill-Direktive | "Watch this transition." | Fokus auf Technik | Watch Completion + Saves |
| Recognition-Hook | "Name this track." | ID-Kultur im Kommentar | Comments (organisch) |
| Kontrast-Statement | "Clubs buchen nach Followern. Tanzflächen nach Sound." | Polarisierung | Shares + Comments |

Deployment-Logik:
```
Gleicher Roh-Clip → 5 Varianten
→ Variante A: Mo TikTok
→ Variante B: Di TikTok
→ Variante C: Mi TikTok
→ Gewinner (höchste Watch Completion + Share Rate) → Instagram (Fr/Sa)
```

Der Completion Rate Hack:
Langes Text-Overlay auf kurzem Video (15–20s) = der Viewer liest während das Video läuft
→ Clip endet bevor Text fertig gelesen → Viewer loopt → Completion Rate steigt
Das ist keine Manipulation, das ist Plattform-Mechanik. Bestätigt durch Pioneer DJ Guide.

### Der #ravetok Recognition-Mechanismus — Organische Comments ohne CTA

Das ist der wichtigste Unterschied zwischen DJ-Content und Self-Brand-Content:

Self-Brand: "Comment hier wenn du X willst" → engineered CTA
DJ: "Name this track." → 200 Comments "ID??" → Community sucht selbst

Das ist das Herzstück der #ravetok-Kultur:
- ACINA postet Bootshaus-Clip → Mashup erkennbar aber Track-ID unklar → 3.4M Likes, 11.5K Comments
- Baby J postet Transition → "What's playing??" — Comments ohne jeden CTA
- Jovynn: 100M+ Views auf einem einzigen Mix-Reveal

"Name this track." ist ein stärkerer CTA als "Comment REMIX for link."
Weil er dem natürlichen Verhalten der Community entspricht — nicht gegen es kämpft.

## Kernmechanismus — Remix-Pipeline mit Copyright-Lösung

### Das strukturelle Problem (und die Lösung)

```
Problem: LINIX remixed fremde Tracks → TikTok erkennt das Audio → Takedown
Lösung:  Audio im Video = ORIGINAL (TikTok-native, kein Takedown-Risiko)
         Visual = LINIX spielt SEINEN Remix auf den CDJs
         Text-Overlay = "My remix." / "Name this track." / "Diese Version."
```

Das original Track als TikTok-Audio gibt algorithmischen Push durch Trending-Audio-Bonus.
Der Viewer sieht seinen Remix visuell. Kein Copyright-Risiko.

| Tool | Was es zeigt | Wie nutzen |

House, Techno, Deep House, Afro House, Melodic Techno.
Mainstream-Pop remixen = falsche Audience aufbauen.

## Content-Produktion — Zwei Umgebungen

### Grundprinzip

```
STUDIO / ZUHAUSE   +   LIVE SHOWS   =   Content-Pipeline die skaliert
  kontrolliert          authentisch
  geplant               emotional
  technisch             Beweis
```

Live-Clips sind Rohmaterial. In Post-Production bekommt jeder Live-Clip
Trending Audio überlagert. Energie vom Club + algorithmischer Push von Trending Audio.

---

### Produktions-Typ A — Studio / Zuhause (40%)

| Shot | Format | Audio |
|---|---|---|
| CDJ-Transition (geprobt) | 15–20s, Close-Up Jog-Wheel | Trending Audio in Post |
| Remix Making-Of im DAW | 20–30s Screenrecording + Hands | Trending Audio in Post |
| "My Remix" Reveal | CDJ-Screen mit Waveform sichtbar | Original-Track (TikTok-native) |
| Equipment Close-up | 15–20s, Slow Reveal | Ambient oder Trending |

Setup-Empfehlung:
- Festes Kamerasetup (Stativ, fester Winkel) — Erkennbarkeit in 3 Sekunden
- Konsistente Beleuchtung → visueller Fingerabdruck aufbauen
- 1–2h Batch-Session → 5–8 Raw-Clips für eine Woche

---

### Produktions-Typ B — Live Shows (60%, sehr wichtig)

Das ist das Material das Studio-Content nicht replizieren kann:
echte Menschen in einem echten Club die auf seinen Sound reagieren.

Shot-Liste — Was bei JEDEM Gig aufgenommen werden muss:

```
PFLICHT (jeder Show):
  □ Crowd-Reaktion beim größten Drop (5–15s)
      → Möglichst breiter Crowd-Shot, Energie sichtbar
      → Ambient-Sound reicht, kein DJ-Ton nötig

  □ CDJ-Screen während seiner Set-Highlights (10–20s)
      → Zeigt dass er spielt, technisches Können
      → Besonders: wenn sein eigener Remix / Edit läuft

  □ Der Moment kurz VOR dem Drop (5–10s)
      → Buildup-Energie, Antizipation

  □ Mindestens 1 Transition-Shot Close-Up (10–15s)
      → Hände auf CDJs, Übergang sichtbar

BONUS (wenn möglich):
  □ Reaktionsshot von ihm bei gelungener Transition
      → Körpersprache = Personality ohne Sprache

  □ Wide-Shot der Venue für Kontext
      → Location-Identität (Stuttgart, Wien, Salzburg)

  □ "Before the gig" Clip — Setup, Soundcheck
      → Behind-the-scenes, niedrige Produktionsanforderung
```

Wer filmt? Muss VOR dem Gig geklärt sein:
- Freund mit Shot-Liste (mitgeben, konkret)
- GoPro am Setup (unbeaufsichtigt, automatisch)
- Venue-Fotograf (um Permission bitten)

Post-Production:
Jeder Live-Clip bekommt Trending Audio überlagert.
Live-Ambiente bleibt leise im Hintergrund (Authentizität).
Trending Audio läuft dominant (Algorithmus-Signal).

ACINA-Format als Orientierung:
Caption: "[Zeit] at [Venue]" + Track IDs + Hashtags
Text-Overlay: Location/Zeit — kein CTA, kein Funnel
Das ist das Format mit 3.4M Likes.

## Was noch fehlt — Ehrliche Lücken

```
1. SOUND IDENTITY:
   Noch keine eindeutige Signature.
   Offene Frage: Was ist der gemeinsame Nenner seiner besten Remixes?
   Das ist seine Sound-Richtung.

2. VISUAL PERSONALITY:
   Ohne Sprache braucht er eine erkennbare visuelle Persönlichkeit.
   Konkret: konsistentes Licht-Setup, ein erkennbarer Kamerawinkel,
   Körpersprache bei Drops/Transitions.
   Das muss vor Video 1 festgelegt werden.

3. FOLLOWER VS. VIEWS — ERWARTUNGSMANAGEMENT:
   Views ≠ Follower. 500K Views können 200 neue Follower bedeuten.
   Der Follow passiert erst wenn jemand mehrmals guten Content sieht.
   LINIX muss das wissen bevor er nach Woche 1 aufgibt.

4. DACH-STRATEGIE BESTÄTIGUNG:
   Test 2 muss bestätigen ob deutsche oder englische Overlays besser performen.
   DACH-Bias ist Hypothese — der Markt entscheidet.
```
