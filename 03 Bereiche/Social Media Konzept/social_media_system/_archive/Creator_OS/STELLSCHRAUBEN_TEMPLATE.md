## Stellschraube 1 — NICHE_VECTOR

*Der Algorithmus braucht Klarheit. Je präziser diese Felder, desto besser das Audience-Matching.*

```
PRIMARY_NICHE:      (z.B. "Personal Finance")
SUB_NICHE:          (z.B. "Debt-Free Journey für Millennials")
AVATAR:             (Eine konkrete Person beschreiben — Alter, Job, Problem, Wunsch)
                    "Mein Avatar ist ___. Er/Sie kämpft mit ___ und will ___."

CONTENT_ANGLE:      (Was ist die einzigartige Perspektive? Warum dieser Creator und nicht 1.000 andere?)
                    "Andere in meiner Nische sagen ___. Ich sage ___."

NICHE_DEPTH:        [ ] Broad  [ ] Focused  [ ] Hyper-Niche
CONSISTENCY_SCORE:  [ ] Themen-chaos  [ ] Grundkonsistenz  [ ] Klar definiert
```

**Diagnose:** Wenn CONTENT_ANGLE nicht in einem Satz formulierbar ist → das ist das erste Problem zu lösen bevor irgendein Content produziert wird.

## Stellschraube 2 — SPCL_AUDIT
*(Hormozi: Influence = Status × Power × Credibility × Likeness × Volume)*

Bewerte den Creator auf einer Skala 1–10:

```
STATUS (1-10): ___
Was kontrolliert dieser Creator das seine Zielgruppe will?
Scarce Resource: ___
Beweis: ___

POWER (1-10): ___
Hat der Creator bereits Erfolge erzielt durch den er seinen Followers geholfen hat?
Say-Do Track Record: ___
Stärkster Beweis: ___

CREDIBILITY (1-10): ___
Wer BESTÄTIGT diesen Creator von außen? (Presse, bekannte Namen, Awards, Screenshots)
Top 3 Third-Party Validations:
  1. ___
  2. ___
  3. ___

LIKENESS (1-10): ___
Wie sehr identifiziert sich das Publikum mit dem Creator?
Gemeinsame Identität / Shared Struggle: ___

SPCL_GESAMT: ___ / 40
```

**Diagnose:**
- Niedrigster Wert = erste Priorität in der Content-Strategie
- CREDIBILITY < 5 → Sofort Third-Party Authority Hooks einbauen
- POWER < 5 → Win-Stories und Ergebnis-Content priorisieren
- LIKENESS < 5 → Avatar-Alignment in Hooks und Sprache verbessern

## Stellschraube 4 — ENEMY_SYSTEM

*Das stärkste Differenzierungs-Werkzeug. Der "Feind" ist ein System oder eine Norm — NIEMALS eine Person.*

```
ENEMY_SYSTEM:       (Das System / die Praxis in der Nische die der Creator entlarvt)
  "Das kaputte System ist: ___"
  "Es schadet meinem Avatar weil: ___"
  "Die meisten machen es so: ___"
  "Ich zeige eine bessere Alternative: ___"

ENEMY_CONTENT_ANGLE:
  "Wenn du [ENEMY_SYSTEM] machst, passiert ___. Ich zeige dir warum und was stattdessen."

INTENSITÄTS-LEVEL:
  [ ] Spielerisch (Präferenzen, Methoden-Unterschiede)
  [ ] Edgy (Industrie-Normen hinterfragen)
  [ ] Scharf (Klarer Gegensatz zu etabliertem Konsens)
```

## Stellschraube 5 — POLARIZING_TOPICS

*Jedes Thema 3× iterieren bis zur maximalen Spezifität. Ziel: echte Reibung.*

```
THEMA 1:
  Iteration 1 (zu vage):    ___
  Iteration 2 (konkreter):  ___
  Iteration 3 (scharf):     ___  ← VERWENDEN

THEMA 2:
  Iteration 1: ___
  Iteration 2: ___
  Iteration 3: ___  ← VERWENDEN

THEMA 3:
  Iteration 1: ___
  Iteration 2: ___
  Iteration 3: ___  ← VERWENDEN

THEMA 4 (optional): ___
THEMA 5 (optional): ___
```

**Regel:** Iteration 3 muss so spezifisch sein, dass sie eine klare Lagerbildung erzeugt. "Sport ist gut" = Iteration 1. "Wer kein Krafttraining macht, verliert ab 30 gegen die Zeit" = Iteration 3.

  ___

## Output — Wird automatisch abgeleitet

*Wenn die 7 Stellschrauben ausgefüllt sind, ergibt sich folgendes:*

### Abgeleitete Hook-Bibliothek (5 personalisierte Templates)

```
Hook 1 — Zahlen-Autorität:
"[PROOF_ASSET_ZAHL] — und heute zeige ich dir wie."

Hook 2 — Bold Claim:
"[POLARIZING_TOPIC iteration 3] — und die meisten machen genau das falsch."

Hook 3 — Curiosity Gap:
"Was [AUTHORITY_REFERENCE] nicht will dass du weißt über [SUB_NICHE]."

Hook 4 — Pattern Interrupt:
"Stopp. Wenn du [COMMON_BEHAVIOR_IN_NICHE] machst, lies das zuerst."

Hook 5 — Transformation:
"Bevor ich [PROOF_ASSET] hatte, dachte ich [COMMON_WRONG_BELIEF]. Das hat sich geändert."
```

### Abgeleitete Plattform-Priorität

```
B2B-Avatar (Unternehmer, Manager, Professionals):
  Primär: LinkedIn → TikTok-Lab → Instagram-Storefront

B2C-Avatar (Consumer, Lifestyle, Entertainment):
  Primär: TikTok-Lab → Instagram-Storefront → YouTube-Trust

Visuell-intensive Nische (DIY, Food, Mode, Interior):
  Primär: TikTok-Lab → Instagram → Pinterest (Evergreen)

Thought Leadership / Text-affin:
  Primär: Threads (Opportunity-Fenster 2026) → LinkedIn → Instagram
```

### Abgeleitetes A/B-Test-Programm (Woche 1-6)

```
Woche 1-2: 5 Videos × 3 Hook-Varianten
  Variable: Hook-Typ (Zahlen vs. Bold Claim vs. Curiosity)
  Konstant: Framework, CTA, Länge
  Auswertung: Watch Time + Completion + ER

Woche 3-4: Top-3-Hooks × 2 Framework-Varianten
  Variable: Story-Framework (Social Proof Tutorial vs. System-Entlarvung)
  Konstant: Hook, CTA

Woche 5-6: Winner-Combo × 2 CTA-Varianten
  Variable: Comment-Lead-Funnel vs. Soft-CTA
  Track: Comment-Rate + DM-Conversion
```
