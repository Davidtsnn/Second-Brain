# TikTok Lab System — Operative Anleitung
**Version:** 1.0 | **Basis:** Universal_Content_Blueprint v5.4
**Gilt für:** Alle Creator im System | **Erstellt:** 2026-05-19

---

## Das Grundprinzip

```
TikTok = Testlabor       → Jeder Hook, jede Caption, jedes Format wird hier getestet
Instagram = Storefront   → Nur bewiesene Winner kommen hier hin
Telegram/Produkt         → Konversion des Instagram-Traffics
```

**Warum TikTok zum Testen?**
- TikTok ER: 3.70% vs. Instagram 0.48% → 7.7× schnelleres Feedback
- TikTok FYP testet mit Non-Follower-Batches → Kein Follower-Aufbau nötig um Daten zu bekommen
- TikTok "verzeiht" schlechte Tests — kein Fit-Score-Vergiftungs-Risiko wie auf Instagram
- Schlechte TikTok-Performer auf Instagram zu posten ist einer der häufigsten Anti-Patterns

**Die Kern-Regel:** Was auf TikTok nicht funktioniert, kommt NICHT auf Instagram.

---

## Das 5-Variationen-Protokoll

### Was "5 Variationen" bedeutet

Für **ein Content-Thema** (z.B. "Forex Risikomanagement") entstehen 5 TikTok-Videos.

```
Konstant (bleibt identisch in allen 5):    Variabel (nur DIESE eine Sache ändert sich):
─────────────────────────────────────────  ──────────────────────────────────────────
• Kerninhalt des Videos                    • Hook (erste 3 Sekunden)
• Länge (21-34 Sek. anstreben)            • Eröffnungssatz (gesprochen)
• CTA am Ende ("SETUP" kommentieren)       • Text-Overlay oben
• Hintergrund / Setting                    • Caption (optional)
• Musik / Energie
```

**Die Single-Variable-Regel:** Nur EINE Variable pro Test ändern.
Sonst kein sauberes Signal — du weißt nicht was gewonnen hat.

## Winner-Kriterien (wann ist ein Video ein Winner?)

### Primärmetrik: Watch Completion Rate
```
≥ 70% Completion Rate   → Starkes Signal, Kandidat für Instagram
50–69%                  → Mittelmäßig, nur deployen wenn alle anderen schlechter
< 50%                   → Nicht deployen
```
*Hinweis: 70%-Threshold = Industrie-Beobachtung, kein offizieller TikTok-Wert. Gut belegt als Orientierung.*

### Sekundärmetriken (Tiebreaker wenn mehrere Videos ähnliche CR haben)
```
Shares/Sends   → Stärkstes Intent-Signal (1 Share ≈ 15 Likes in Reach-Wert)
Comments       → Engagement-Tiefe, zeigt Meinungsbildung
Saves          → Evergreen-Signal, Nutzer will es wiedersehen
Likes          → Schwächstes Signal, ignorieren als Haupt-Kriterium
```

### Minimum bevor du einen Winner callst
```
Mindest-Views:    500 Views (sonst kein statistisch belastbares Signal)
Beobachtungsfenster: 48 Stunden nach Posting
```

## Entscheidungsbaum — Was kommt auf Instagram?

```
Nach 48h und 500+ Views:

Gibt es einen klaren Winner (>70% CR, mindestens 1.5× besser als Platz 2)?
  ↓ JA → Diesen Hook auf Instagram deployen
  ↓ NEIN ↓

Gibt es 2 Videos mit >70% CR?
  ↓ JA → Beide als Trial Reels auf Instagram testen, Instagram entscheidet
  ↓ NEIN ↓

Alle Videos unter 70% CR?
  → Concept nicht deployen. Thema oder Kerninhalt überarbeiten.
  → Analyse: War der Inhalt schwach oder nur alle Hooks schlecht?
  → Wenn Inhalt schwach → neues Thema
  → Wenn Hooks schwach → neue Hooks für dasselbe Thema testen
```

## Wochenrhythmus (operativ)

```
MONTAG      Post TikTok A (System-Entlarvung Hook)
            Post TikTok B (Zahlen-Paradox Hook)

DIENSTAG    Post TikTok C (Pattern Interrupt Hook)

MITTWOCH    Post TikTok D (Bold Claim Hook)
            Post TikTok E (Transformation Arc Hook)

DONNERSTAG  Daten auswerten
            → TikTok Analytics: Completion Rate, Shares, Comments
            → Winner callen nach Entscheidungsbaum

FREITAG     Winner für Instagram adaptieren (Wasserzeichen entfernen, Caption anpassen)

SAMSTAG/SO  Winner auf Instagram posten
            (3-7 Tage Abstand zum ersten TikTok-Post ist optimal)
```

## TikTok → Instagram: Der Adaptions-Checklist

```
Vor dem Instagram-Post:

[ ] 1. TikTok-Wasserzeichen entfernen
       → Video ohne Wasserzeichen direkt aus TikTok herunterladen
       → ODER: Original-Video ohne TikTok hochladen
       → Instagram Originality Score 2026 bestraft Watermark-Videos

[ ] 2. Caption anpassen
       → TikTok Caption: kurz, 1-2 Zeilen, Keyword-fokussiert
       → Instagram Caption: länger, mehr Kontext, klarer CTA, 3-5 Hashtags
       → Nicht einfach kopieren — Instagram-Nutzer lesen Captions mehr

[ ] 3. Als Trial Reel starten (Pflicht für erste 4 Wochen)
       → Instagram zeigt Trial Reels zuerst Non-Followern
       → 24-72h Beobachtungsfenster
       → Nur wenn Trial Reel >Benchmark: als normaler Post freigeben

[ ] 4. Posting-Zeitpunkt prüfen
       → Beste Zeiten DACH: Di-Do, 18-21 Uhr
       → Ersten 60 Min. nach Posting: nicht schlafen, aktiv auf Kommentare antworten

[ ] 5. CTA im Video ist identisch
       → "SETUP" kommentieren → ManyChat DM
       → Gleicher CTA auf TikTok und Instagram
```

## Caption-Struktur (TikTok vs. Instagram)

### TikTok Caption (kurz + Keyword)
```
[Hook wiederholen oder verstärken — 1 Satz]
[Kontext — 1 Satz]
[CTA: "SETUP kommentieren für mein Risk Template"]
#forex #forextrading #trading #forexdeutsch #moneytips
```

### Instagram Caption (länger + Kontext + SEO)
```
[Hook als erster Satz — stark, scroll-stoppend]

[2-3 Sätze Kontext: Was ist das Problem? Warum sollte der Leser weiterlesen?]

[Kern-Inhalt in 3-5 kurzen Bullet Points oder Absätzen]

[Social Proof wenn vorhanden: "Myfxbook zeigt X% diesen Monat"]

[CTA: "Kommentiere SETUP und ich schicke dir mein Risk Management Template kostenlos"]

.
.
#forex #forextrading #forexsignals #forexdeutsch #trading #daytrading
#riskmanagement #tradingstrategy #forexlifestyle #passiveeinkommen
```

## Muster-Erkennung (nach 6+ Wochen)

Ab Woche 7 kannst du anfangen Muster zu sehen:

```
Welcher Hook-Typ gewinnt am häufigsten?
  → Das ist dein dominanter Hook-Typ — öfter verwenden

Welcher Hook-Typ verliert immer?
  → Weglassen oder deutlich seltener testen

Was ist das Thema der besten Videos?
  → Mehr davon produzieren

Welche Videos gehen auf TikTok UND auf Instagram?
  → Das ist dein Content-Archetype — dokumentieren in KNOWLEDGE_DATABASE.md
```

## Anti-Patterns (was du vermeiden musst)

```
✗ Mehrere Variablen gleichzeitig ändern
  → Wenn Hook UND Caption UND Musik anders sind, weißt du nicht was gewonnen hat

✗ Unter 500 Views als Winner callen
  → Zu wenig Daten, zu viel Zufall

✗ TikTok-Wasserzeichen auf Instagram lassen
  → Instagram Originality Score 2026 bestraft das explizit

✗ Schlechte TikTok-Performer auf Instagram deployen
  → "If it didn't work there, it won't work here"

✗ Alle 5 Videos am selben Tag posten
  → TikTok bestraft Massen-Posting, Algorithmus klassifiziert deinen Account neu
  → Spread über Mo-Mi (2-1-2 Rhythmus)

✗ Nischen-Wechsel in den ersten 30 Tagen
  → TikTok Algorithmus braucht 30 Tage um deinen Account zu klassifizieren
  → Jeder Themen-Wechsel zerstört das bisherige Matching
```

## Skalierbares Produktions-System (wenn Volumen steigt)

```
Pro Woche: 1 Thema → 5 Hooks → 1 Winner auf Instagram

Aufwand pro Woche (realistisch):
  Filmen:        60-90 Min. (alle 5 Videos am selben Tag, nur Hook-Intro variieren)
  Schneiden:     60 Min. (5× schneller Cut, gleiche Struktur)
  Posten:        20 Min. verteilt auf Mo-Mi
  Auswerten:     15 Min. Donnerstag
  IG-Adaption:   20 Min. Freitag
  ─────────────────────────────
  Gesamt:        ~3-4 Stunden pro Woche für einen vollständigen Test-Zyklus

Effizienz-Tipp: Alle 5 Videos an einem Drehtag aufnehmen.
  → Gleicher Hintergrund, gleiches Outfit, gleiche Energie
  → Nur die ersten 5-8 Sekunden sind verschieden (Hook)
  → Rest des Videos ist identisch (aufnehmen, Hook davor schneiden)
```
