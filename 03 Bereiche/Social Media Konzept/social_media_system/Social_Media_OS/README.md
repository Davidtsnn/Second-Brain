# Social Media OS

**Ein universelles Konzept für Social-Media-Wachstum.**
Keine Nische. Keine Zielgruppe. Keine Templates.
Nur die Mechaniken die auf jeder Plattform, für jeden Creator, in jeder Nische funktionieren.

---

## Was das ist

Dieses System ist kein Agentur-Tool und kein Onboarding-Template.
Es ist die Destillation aus 24 Forschungsrunden, 55+ Quellen und direkter Praxis-Erfahrung.

Das Ergebnis: Ein vollständiges Bild davon wie Social Media wirklich funktioniert — algorithmisch, psychologisch, beziehungs-getrieben. Es geht ausschließlich um Content.

---

## Wie du es nutzt

Lies das Playbook einmal von oben bis unten. Dann nutze einzelne Kapitel als Referenz.

```
MASTER_PLAYBOOK.md    ← Algorithmus, Content, Wachstum
FUNNEL.md             ← Content-Funnel-Konzept (Fremder → Superfan, als Kreislauf)
PLATFORMS.md          ← Plattform-spezifische Regeln 2026 (Referenz)
```

---

## Die Kernthese

> Social Media ist kein Kreativitätswettbewerb. Es ist ein Empfehlungsalgorithmus der nach Verhaltens-Signalen rankt.
> Wer die Signale versteht, gewinnt — unabhängig von Nische, Follower-Zahl oder Budget.
