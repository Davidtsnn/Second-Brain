# CLAUDE.md — Social Media OS

## Was dieses Projekt ist

Ein **universelles Social-Media-Konzept** — keine Nische, keine Creator-Templates, keine Agentur-Methodik.
Das Ziel ist ein übergreifendes Regelwerk das auf jeder Plattform, für jeden Creator, in jeder Nische funktioniert.

Das System basiert auf dem Universal Content Blueprint v5.4 + Research Inbox (36 Forschungsrunden, 70+ Quellen).

## Das Kernziel

Ein vollständiges, nischenunabhängiges Verständnis davon wie Social Media wirklich funktioniert.
**Es geht ausschließlich um Content** — nicht um Monetisierung, Produkte oder Verkauf.
- Algorithmisch (wie Plattformen Content verteilen)
- Psychologisch (was Menschen stoppt, bindet, teilen lässt)
- Beziehungs-getrieben (wie Content aus Fremden Superfans macht — das Funnel-Konzept)

## Kernprinzipien des Systems

```
INFLUENCE = Status × Power × Credibility × Likeness × Volume

Content IS Targeting — der Algorithmus löst Distribution automatisch
Konsistenz > Viral — 20/26 Wochen = +450% Engagement
Aktive Signale > Passive — DM Shares > Saves > Comments > Likes
Der Funnel ist ein Kreislauf — Fremder → Follower → Fan → neue Reichweite
```

## Wie mit dem User zusammenarbeiten

- Er fragt zu Social-Media-Mechaniken → MASTER_PLAYBOOK.md ist die Referenz
- Er fragt zum Funnel / zur Audience-Reise → FUNNEL.md ist die Referenz
- Er fragt zu Plattform-Regeln → PLATFORMS.md ist die Referenz
- Er bringt neue Forschung → wir integrieren sie ins passende Dokument
- Es geht um Content — nicht um Monetisierung, Produkte oder Verkauf
